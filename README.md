OpenBLAS Import Wrapper Library for Visual Studio
================================================
Rindow OpenBLAS VClib allows for the importing and calling of VC-format DLLs, regardless of the OpenBLAS build number.

Overview
--------

Generally, when developing C/C++ applications using DLLs and LIB files created in Microsoft Visual Studio, the versions of the DLL and the LIB must match exactly. Furthermore, any program linked against a specific LIB file must be used with the corresponding DLL, as function calls rely on an address table embedded within the LIB. If the DLL is rebuilt—even with minor modifications—the address table will no longer align with the linked LIB, rendering the DLL calls non-functional.

A common workaround is for the application to bypass the LIB files automatically generated by Microsoft Visual Studio and instead use the Windows API function `GetProcAddress` to retrieve function addresses based on their names (as strings). This approach accommodates changes to function addresses. Typically, application developers must implement this process individually within each of their projects.

This library handles such dynamic name resolution on your behalf. By linking this library—instead of the LIB files automatically generated by Microsoft Visual Studio—you can provide users with applications that are independent of specific DLL build versions.

Requirements
------------

- [CLBlast for Windows](https://github.com/OpenMathLib/OpenBLAS/releases)
- [OpenCL-SDK](https://github.com/KhronosGroup/OpenCL-SDK)
- [Microsoft Visual Studio](https://visualstudio.microsoft.com/)

How to setup pre-build binaries
-------------------------------

### How to setup for Windows

Download the pre-build binary file.

- https://github.com/rindow/rindow-clblast-vclib/releases
- https://github.com/CNugteren/CLBlast/releases
- https://github.com/KhronosGroup/OpenCL-SDK/releases

Unzip the file for Windows and copy the files to the directory set in PATH.


How to build from source code on Windows
----------------------------------------
You can also build and use from source code.

### Download source code

Download source code from release and unzip

- https://github.com/rindow/rindow-clblast-vclib/releases
- https://github.com/CNugteren/CLBlast/releases
- https://github.com/KhronosGroup/OpenCL-SDK/releases

### Build and Install on Windows

Build with Visual Studio.

```shell
C> cd \path\to\here
C> cmake -S . -B build -DCLBLAST_DIR=/path/to/CLBlast/sdk/dir -DOPENCL_DIR=/path/to/OpenCL-SDK/dir
C> cmake --build build --config Release
C> cd build
C> ctest -C Release
C> cpack -C Release
C> cd ..\packages
```

Unzip the package file from packages directory.
